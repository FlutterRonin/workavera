# 文档公开链接产品需求文档

[English](./docs-public-links-prd.md)

> 实现基线：Workavera `0.2.0`，于 2026-10-29 按提交 `7d8d88d` 核验。文档公开链接于 `0.1.0` 上线；在新标签页中打开链接，以及从项目公开时间线打开文档，于 `0.1.1` 新增。

## 1. 产品目的

文档公开链接让 [Docs](./docs-prd.zh-CN.md) 文档的创建者把文档的某一版发布到一个不可猜测的链接，任何人无需账号即可阅读——比如发给客户的方案、给团队外读者的指南——而编辑仍在工作区里私下继续。

## 2. 目标

- 文档创建者可以把文档发布为公开链接，并可选设置过期时间。
- 链接只提供已发布的那一版，之后的编辑在创建者重新发布前保持私密。
- 创建者可以看到哪一版是公开的，重新发布最新版，修改或清除过期时间，以及撤销链接。
- 链接被撤销、过期，或文档被归档、删除时立即失效，且不透露是哪种情况。
- 给读者一个干净的页面：Markdown 带进度条和目录，HTML 在编辑器的沙箱中呈现。
- 只开放已发布版本所引用的附件。

## 3. 非目标

- 跟随实时文档变化、可被猜到、可被列出，或允许评论和编辑的链接。
- 由创建者以外的项目成员或由助手发布。
- 密码保护的链接、访问计数或统计分析。
- 一篇文档有多个链接。
- 公开页面使用自定义域名或路径。

## 4. 数据模型

### `doc_shares`

| 字段 | 规则 |
| --- | --- |
| `doc` | 必填，唯一，关联文档；随文档一起删除。 |
| `slug` | 唯一的 22 位小写字母和数字组成的公开标识，由服务端生成。 |
| `revision` | 已发布的版本号，从 `doc_versions` 读取。 |
| `expires` | 可选；为空表示链接不过期。 |
| `created_by` | 发布链接的创建者。 |

分享是一条独立的记录，因此发布、设置过期和撤销都不会改动文档本身，也不会产生新版本。所有者通过 PocketBase 的 list 和 view 规则读取自己的分享；所有写入都经过 Docs API，客户端既不能自选 slug，也不能手动指定版本。

## 5. 行为

- 发布一篇还没有链接的文档，会以它的当前版本创建链接。
- 带 **republish** 再次发布会把链接移到当前版本；只修改过期时间不会移动版本。
- 撤销会删除分享记录，因此再次发布会生成新的 slug，而不是恢复旧链接。
- slug 不存在、链接已过期，或文档已归档、已删除时，链接都不可用，且几种情况的响应完全一致。
- 只有已发布版本的内容引用了某个附件，才能通过链接访问该附件；发布之后上传的附件保持私密。

## 6. 用户体验

- 创建者在文档工具栏中分享。对话框可以创建链接、复制链接、在新标签页打开、对比已发布版本和当前版本、按需发布最新版、设置或清除过期时间，以及撤销链接。
- 公开文档在已登录应用之外的 `/s/{slug}` 打开，文档周围没有任何页面框架：文档自己的标题就是页面标题，文档名只用作浏览器标签页的标题。不可用的链接只提示"不可用"。
- 公开的 Markdown 以只读方式呈现，顶部有滚动进度条；在宽屏上，旁边还有文档标题组成的目录，会高亮当前章节并可跳转到任意章节。公开的 HTML 在与编辑器预览相同的沙箱隔离源中呈现，不提供这两项阅读辅助。
- [项目公开时间线](./board-public-preview-prd.zh-CN.md)通过文档自己的公开链接打开任务关联的文档；没有公开链接的文档只显示名称，无法打开。

## 7. HTTP API

- `GET /api/docs/{id}/share` 返回文档当前的链接（如果有）。
- `POST /api/docs/{id}/share` 发布、修改过期时间或重新发布。
- `DELETE /api/docs/{id}/share` 撤销链接。
- `GET /api/public/docs/{slug}` 返回已发布版本的标题、类型、内容、版本号和发布时间。
- `GET /api/public/docs/{slug}/assets/{assetId}` 提供已发布版本所引用的附件。

这两个公开接口是匿名访客唯一能访问的接口。所有者、项目、文件夹和编辑者的身份信息永远不会离开服务端。它们是自定义接口，因为内置规则无法把 slug 解析到另一个集合的记录、处理过期并剥离私有字段；附件按 slug 代理，因为受保护的文件需要文件 token，而匿名访客无法获得。

## 8. 权限

- 只有文档创建者可以发布、重新发布、设置过期时间或撤销链接，与归档和删除一致。项目成员身份不赋予分享权限。
- 助手没有操作公开链接的工具。

## 9. 验收标准

1. 创建者可以发布、复制、打开、重新发布链接，设置和清除过期时间，以及撤销链接；其他人都不能。
2. 匿名访客能看到已发布的版本、标题及其引用的附件，看不到所有者、项目或文件夹的任何信息。
3. 发布之后的编辑在创建者重新发布之前保持私密，修改过期时间不会触发重新发布。
4. 已撤销、已过期、已归档或已删除文档的链接一律显示为不可用，不透露具体原因；撤销后再次发布会得到新链接。
5. 发布之后上传的附件无法通过链接访问。
6. 项目公开时间线可以打开已公开的关联文档，无法打开未公开的文档。
