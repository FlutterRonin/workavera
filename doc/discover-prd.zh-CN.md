# Discover 产品需求文档

[English](./discover-prd.md)

> 实现基线：Workavera `0.2.0`，于 2026-10-29 按提交 `7d8d88d` 核验。Discover 于 `0.1.1` 上线。

## 1. 产品目的

Discover 是 [Reading](./reading-prd.zh-CN.md) 里的一个面板，用来抓取用户订阅源当下的内容——RSS、Atom 订阅源和 GitHub Trending 列表——让新链接无需离开工作区就能浏览、总结和保存。它为稍后读列表提供内容，而不是取代其中任何部分：用户保留的候选项会成为一个普通的稍后读条目。

## 2. 目标

- 每位用户可以维护私有的订阅：RSS 或 Atom 订阅源，以及指定语言和周期的 GitHub Trending 列表。
- 每个新账号默认带有几个实用的订阅。
- 按需抓取所选订阅，并把各订阅的条目汇总成一个候选列表。
- 标记出哪些候选项已在稍后读列表中。
- 决定是否保留之前，可以先按所选语言总结任意候选项。
- 一步把候选项连同总结加入稍后读列表。

## 3. 非目标

- 后台或定时抓取；Discover 只在用户要求时抓取。这个方向见[定时任务提案](./scheduled-tasks-prd.zh-CN.md)。
- 在服务端保存候选项，或记录抓取历史。
- 新条目通知。
- 需要鉴权的订阅源，以及 RSS、Atom、GitHub Trending 以外的来源。
- Discover 的助手工具。

## 4. 数据模型

### `reading_sources`

| 字段 | 规则 |
| --- | --- |
| `owner` | 必填，关联用户；不可更改。 |
| `name` | 必填，显示名称，最长 100 个字符。 |
| `kind` | `rss`（RSS 或 Atom 源）或 `github_trending`。 |
| `url` | `rss` 类型必填：`http` 或 `https` 的订阅地址。 |
| `params` | `github_trending` 类型使用：必填的 `language`，以及取值为 `daily`、`weekly` 或 `monthly` 的 `since` 周期。 |
| `enabled` | 停用的订阅会保留，但不会被抓取。 |
| `last_fetched_at`、`last_error` | 最近一次抓取的结果。 |

订阅使用 PocketBase 自带的增删改查，规则把所有操作限制在所有者本人；另有钩子拒绝缺少有效订阅地址的 RSS 订阅，以及缺少语言的 GitHub Trending 订阅。

每个新账号默认有 4 个已启用的订阅：Go、Rust、TypeScript 的每周 GitHub Trending，以及 Hacker News 首页。预置订阅只是为了方便；即使创建失败，账号也照常创建。

## 5. 抓取与候选项

- 抓取会并行读取所选的已启用订阅，整个请求限时 60 秒。
- 每个订阅源最多贡献 30 条；Trending 列表贡献页面上的仓库，包括描述、语言、总星数以及该周期内新增的星数。
- 面板最多显示 200 个候选项，并按 URL 去重。
- 某个订阅抓取失败不会清空面板：它的错误会和其他订阅的候选项一起显示，并保存到 `last_error`。抓取成功会清空错误，并记录 `last_fetched_at`。
- Trending 仓库按该周期内新增的星数排序，排在订阅源条目之前；订阅源条目保持各自原有的顺序。
- URL 已在用户稍后读列表中的候选项会被标记出来。
- 总结候选项会抓取其页面并调用用户的默认模型，方式与总结稍后读条目完全相同，语言由用户选择。
- 加入候选项会以其标题和 URL 创建一个稍后读条目；如果已经生成过总结，会一并带上总结和要点。

## 6. 用户体验

- Discover 从 Reading 侧边栏的闪光按钮打开，是一个分为**候选**和**订阅**两个标签页的对话框。
- **候选**页把已启用的订阅显示为可选的标签，提供**抓取**按钮，并以卡片显示结果，包括来源、描述以及日期或新增星数。每张卡片都可以总结，并加入稍后读列表。
- **订阅**页列出所有订阅及其类型和上次的结果，用户可以添加、编辑、启用、停用和删除订阅。RSS 订阅需要填写订阅地址；GitHub Trending 订阅需要选择语言和周期。

## 7. 权限

- 订阅是私有的：只有所有者可以列出、查看、创建、更新或删除，且所有者不可更改。
- 抓取和总结都走需要登录的接口，并且只读取调用者自己的订阅。
- 页面由服务端以 `Workavera/1.0` 的 User-Agent 抓取，并有大小限制。

## 8. 验收标准

1. 新账号能看到 4 个预置订阅。
2. 用户可以添加、编辑、停用和删除自己的订阅，无效的 RSS 或 Trending 订阅会被拒绝。
3. 抓取多个订阅时返回去重后的候选项，标记已保存的条目，并在不隐藏其他结果的前提下报告失败的订阅源。
4. 候选项可以总结并加入列表，之后会标记为已在稍后读列表中。
5. 其他用户无法查看或抓取别人的订阅。
