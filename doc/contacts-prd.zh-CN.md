# Contacts 产品需求文档

[English](./contacts-prd.md)

> 实现基线：Workavera `0.2.0`，于 2026-10-29 按提交 `7d8d88d` 核验。

## 1. 产品目的

Contacts 是 Workavera 的团队通讯录。实例中的每位应用用户都会出现在这里，展示他们自己维护的资料——姓名、职位、状态、头像和联系方式——方便队友互相找到对方，也让助手在分配任务或添加项目成员时能把名字对应到具体的人。

## 2. 目标

- 列出工作区的所有用户，最新加入的排在前面。
- 按姓名、邮箱或职位搜索，并按状态过滤。
- 每位用户可以维护一份私有的收藏联系人列表，显示在其他人之前。
- 在详情面板中展示联系人的完整资料。
- 让 Chat 搜索联系人，返回的信息不包含个人联系方式。

## 3. 非目标

- 外部联系人、公司或 CRM；Contacts 只列出本实例的用户。
- 在 Contacts 中创建、编辑或移除其他用户；账号由超级管理员在 PocketBase 后台管理，每位用户编辑自己的资料。
- 分组、团队或组织架构图。
- 在 Contacts 中发消息或打电话。
- 导入或导出联系人。

## 4. 数据模型

### `users`（Contacts 读取的字段）

| 字段 | 用途 |
| --- | --- |
| `name`、`title`、`bio` | 显示在列表和详情面板中；由用户在 Profile 中编辑。 |
| `email` | 在 PocketBase 允许其他用户看到时显示。 |
| `phone` | 只在详情面板中显示。 |
| `status` | `online`、`away`、`busy` 或 `offline`（默认）。 |
| `avatar` | 头像。 |

任何已登录用户都可以列出和查看用户；只有用户本人可以更新自己的记录。

### `contact_favorites`

| 字段 | 规则 |
| --- | --- |
| `owner` | 收藏的所有者，必须是当前登录用户。 |
| `contact` | 被收藏的用户，不能是所有者本人。 |

收藏仅对所有者可见，所有者可以列出、创建和删除。收藏没有更新规则：只能添加或移除，不能编辑。

## 5. 用户体验

- Contacts 位于 `/contacts`。搜索框按姓名、邮箱和职位过滤，状态标签可以把列表缩小到某一种状态。
- 列表分为**收藏**和**全部联系人**两部分，每部分都是最新加入的排在前面。
- 每一行显示头像、姓名、职位、状态和邮箱，收藏的联系人带星标；行内菜单可以打开资料，以及添加或取消收藏。
- 选中联系人会打开详情面板，展示包括电话和简介在内的完整资料。

## 6. 权限与隐私

- Contacts 只显示用户自己填写在资料中的内容。
- 收藏只对创建它的用户可见。
- 助手拿到的信息只有 ID、姓名、职位、状态和头像，不包含邮箱、电话或简介，因为工具结果会发送给所选的模型服务商。

## 7. 助手工具

### `contacts_search`

按姓名或职位搜索用户，最多返回 20 个结果，只包含上述不敏感的信息。Chat 用它在分配任务、添加项目成员或回答"某人是谁"之前先找到对应的人。

该工具同样可以通过 API Key 提供给 MCP 客户端，见 [MCP 接入 PRD](./mcp-server-prd.zh-CN.md)。

## 8. 已知问题

- 已停用的账号仍会出现在 Contacts 和 `contacts_search` 的结果中。产品中体现停用状态后，应隐藏或标记这些账号。

## 9. 验收标准

1. 已登录用户能在 Contacts 中看到本实例的所有用户，最新加入的排在前面。
2. 按姓名、邮箱或职位搜索，以及按状态过滤，都能按预期缩小列表。
3. 用户可以收藏和取消收藏其他用户，不能收藏自己，也永远看不到别人的收藏。
4. 详情面板展示联系人的完整资料。
5. `contacts_search` 能按姓名或职位找到用户，且从不返回邮箱、电话或简介。
